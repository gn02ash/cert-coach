## Audience profile

Candidates design, build and operate AI-powered applications on a cloud platform.

## Skills at a glance

- Plan and manage an AI solution (20–25%)
- Build generative AI applications (30–35%)
- Implement retrieval-augmented generation (20–25%)
- Monitor and secure AI workloads (15–20%)

## Plan and manage an AI solution (20–25%)

### Select the right AI services

- Choose a model for a text generation scenario
- Choose between hosted models and self-hosted open models
- Estimate token usage and cost for a workload

### Plan deployment and quotas

- Plan regional deployment for latency and data residency
- Configure quotas and rate limits

## Build generative AI applications (30–35%)

### Engineer prompts

- Write system prompts with clear roles and constraints
- Use few-shot examples to steer output format
- Request structured output with a JSON schema

### Orchestrate tools and agents

- Define tools with typed parameters
- Handle multi-step tool calls in an agent loop
- Expose application capabilities through an MCP server

## Implement retrieval-augmented generation (20–25%)

### Prepare content

- Extract text from PDF documents
- Chunk documents with overlap
- Generate and store embeddings in a vector database

### Retrieve and ground answers

- Combine vector and keyword search
- Cite sources in generated answers
- Evaluate retrieval quality with a test set

## Monitor and secure AI workloads (15–20%)

### Observe

- Trace prompts, tool calls and latency
- Track token usage and cost over time

### Secure

- Store keys outside source code
- Apply content filtering to inputs and outputs
